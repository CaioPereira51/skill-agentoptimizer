### 🛠️ Skills Usadas como Referência

Este projeto não nasceu do zero! Ele foi inspirado e utiliza conceitos das seguintes ferramentas e skills incríveis no ecossistema de agentes autônomos:

* 📄 **[session-report](https://github.com/cline/skills)**: Encontrado no repositório de skills do Cline e derivados. 
  *(Nota: Há também uma variação popular chamada `session-reporting` no ecossistema Aether, disponível [aqui](https://skills.rest/skill/session-reporting)).*
* 💡 **[How I Prompt](https://github.com/eeshansrivastava89/howiprompt)**: Ferramenta de analytics local para entender seus padrões de uso e prompts com agentes de IA.
* 📈 **[skillusage](https://github.com/UCSB-NLP-Chang/Skill-Usage)**: Framework de avaliação para uso de skills por agentes (da UCSB NLP).
* ⚙️ **[ccusage](https://github.com/ccusage/ccusage)**: CLI para ler dados locais de ferramentas/agentes (como o Cursor) e gerar relatórios de uso de tokens, custos e cache.
* 🔬 **[OpenLIT](https://github.com/openlit/openlit)**: Plataforma open-source com OpenTelemetry para observabilidade, custos e testes em fluxos de agentes (Agentic Workflows).
* 🎯 **[AgentOptimizer (AgentOpt)](https://github.com/AgentOptimizer/agentopt)**: Repositório focado em encontrar automaticamente a melhor combinação de modelos (planejador/executor) otimizando custo e precisão para agentes.
  *(Nota: Sobre o AgentOptimizer original do AutoGen da Microsoft, a documentação e implementação ficam [aqui](https://microsoft.github.io/autogen/0.2/docs/notebooks/agentchat_agentoptimizer/)).*


2. Instale e execute (Substitua pelos comandos reais do seu projeto):
